# Pratap Coaching Classes

Static, responsive education-institute website.

## Files

- `index.html` — website structure and content
- `css/style.css` — complete responsive styling
- `js/main.js` — mobile menu, FAQ, forms and brochure-download interactions
- `assets/` — local asset folder, ready for future images, logos or brochures

## Upload to GitHub

1. Create a new GitHub repository.
2. Upload `index.html`, `css/`, `js/`, `assets/` and this `README.md` to the repository root, keeping the same folder structure.
3. For a live website, open **Settings → Pages**, choose **Deploy from a branch**, and select the `main` branch with the `/ (root)` folder.

No build step is required. The site uses public Google Fonts and Font Awesome CDN links.
